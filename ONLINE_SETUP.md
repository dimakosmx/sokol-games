# SOKOL GAMES — подключение общего рейтинга

## 1. Настрой базу данных (один раз)
1. В Supabase открой проект с адресом `https://aqsefijtbvtlwcymqofu.supabase.co`.
2. В **SQL Editor → New query** открой файл `supabase_setup.sql` из этого архива, скопируй **весь** SQL и нажми **Run**.
3. Файл не удаляет таблицу `leaderboard`, которая уже существует. Если ранее создавались дополнительные INSERT/UPDATE policies, отключи их в Table Editor → leaderboard → Policies: браузеру необходим только SELECT; сохранение происходит через RPC `submit_game_score`.
4. Проверь в разделе Database → Functions, что появилась `submit_game_score`.

## 2. Проверка локально
Распакуй архив и открой `sokol-games/index.html`. В каждой игре под полем находится ТОП-5. Если настройка БД ещё не завершена, будет показано уведомление об офлайн-рейтинге.

## 3. Обнови GitHub Pages
В существующем репозитории `sokol-games` загрузи все изменённые файлы в КОРЕНЬ проекта, в том числе новые `supabase-config.js` и `supabase_setup.sql` (последний можно не публиковать, он нужен только для настройки базы). Зафиксируй Commit changes. Не загружай ZIP внутрь репозитория.

## 4. Как тестировать
Открой сайт в двух разных браузерах/устройствах. Заверши Apple Catcher с ненулевым счётом, введи имя, нажми «Продолжить», обнови игру на другом устройстве. Если SQL выполнен и Supabase доступен, результат появится в общем рейтинге.

### Безопасность и ограничения
- В `supabase-config.js` только **публичный** publishable key — он предназначен для браузеров. Никогда не помещай в проект пароль БД, `service_role` или `sb_secret_*`.
- Прямая запись в таблицу отключена; запись происходит через ограниченную SQL-функцию. Но таблица рекордов *не защищена от накрутки очков*: браузер сообщает свой счёт, а пользователь может подделать запрос. Для серьёзного турнира нужен серверный подсчёт очков, учётные записи и полноценное ограничение спама.
- Личный максимум хранится на данном устройстве, а глобальный ТОП-5 — в Supabase.
- Если Supabase не отвечает, показываются локальные результаты. Они не синхронизируются автоматически позже.
- Для Pong Arena два игрока вводят имена отдельно. Если один и тот же ник используется разными людьми, сохраняется максимальный результат для этого ника.
