# SOKOL GAMES 🎮

Готовый адаптивный сайт-каталог мини-игр для компьютера и телефона. Не нужен сервер базы данных, платная подписка или сборщик проекта.

## Быстрый запуск

1. Распакуй ZIP в папку `sokol-games`.
2. Открой файл `index.html` в Chrome или Edge двойным щелчком.
3. Нажми «Выбрать игру», затем «Играть сейчас» на карточке **APPLE CATCHER** или **NEON DODGE**.

**APPLE CATCHER** уже встроена и работает офлайн. Оригинал: `lucky_bombs.pde`. В браузерной версии есть яблоки, бомбы, 3–5 жизней, Lucky Block, 8 эффектов рулетки и рестарт. Управление — стрелки ← →, касание на телефоне и мышь.

Некоторые браузеры могут ограничивать доступ к `localStorage` для файлов `file://` — тогда рекорды или избранное не будут сохраняться. Для надёжной проверки используй локальный сервер:

```bash
cd sokol-games
python -m http.server 8000
```

Затем открой `http://localhost:8000` (на Windows может потребоваться команда `py -m http.server 8000`).

## Как добавить свою игру из Processing

Processing в режиме Java НЕ запускается напрямую в браузере. Сначала игру нужно **переписать/перенести на JavaScript с p5.js** (или использовать другой браузерный игровой движок).

1. Создай папку, например `games/apple-catcher/`.
2. Помести в неё `index.html` со встроенной игрой или подключением к `sketch.js` (все ресурсы должны быть доступны по относительным путям).
3. Открой `games.js` и измени карточку `apple-catcher`:

```js
{
  id: "apple-catcher",
  title: "APPLE CATCHER",
  subtitle: "Лови яблоки, избегай динамита",
  genre: "Реакция",
  status: "ready",
  url: "games/apple-catcher/index.html",
  icon: "🍎",
  colors: ["#0f8168", "#bfe557"],
  controls: "Стрелки ← →"
}
```

Важно: должна существовать указанная HTML-страница игры. Сам Processing `.pde` загрузить вместо HTML нельзя.

Чтобы создать новую карточку, добавь ещё один объект в массив `GAMES` в `games.js`. У каждой игры должен быть уникальный `id`.

### Минимальный шаблон p5.js

Для браузерной игры можно создать `games/my-game/index.html`:

```html
<!doctype html>
<html lang="ru">
<head><meta charset="utf-8"><meta name="viewport" content="width=device-width, initial-scale=1"></head>
<body style="margin:0;background:#080c20">
<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.11.11/p5.min.js"></script>
<script src="sketch.js"></script>
</body>
</html>
```

В файле `sketch.js` — адаптированный JavaScript-код игры. Библиотеку p5.js шаблон загружает через интернет; для работы полностью офлайн нужно сохранить библиотеку локально и поменять путь в `script src`.

## Публикация — GitHub Pages (бесплатно)

1. Создай аккаунт на https://github.com/ (если его ещё нет).
2. Создай **публичный** репозиторий с именем `sokol-games`.
3. Загрузи **содержимое папки** `sokol-games` в корень репозитория: `index.html`, `styles.css`, `app.js`, `games.js`, `games/`. В веб-интерфейсе репозитория можно выбрать **Add file → Upload files** и подтвердить загрузку (Commit changes).
4. Открой **Settings → Pages**. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Укажи ветку `main` и папку `/ (root)`, нажми **Save**.
6. После публикации открой адрес `https://ТВОЙ-ЛОГИН.github.io/sokol-games/` (точный адрес будет в разделе Pages).

Публикация может занять некоторое время. Сайт публичный: любой с ссылкой сможет его посетить. Для обновления каталога загружай обновлённые файлы в тот же репозиторий.

## Файлы

- `index.html` — страницы каталога и окно игры.
- `styles.css` — неоновый дизайн и адаптация под телефоны.
- `games.js` — настройки каталога; **именно здесь добавляются игры**.
- `app.js` — поиск, фильтры, избранное, окно игры и звуки интерфейса.
- `games/demo/index.html` — готовая игра NEON DODGE.

Избранное и рекорды хранятся локально в браузере конкретного устройства, а не в общей онлайн-таблице. На другом телефоне или компьютере результаты автоматически не появятся.

Примечание: для оформления сайт загружает веб-шрифты Google Fonts. При отсутствии интернета они заменяются системными шрифтами.


### Pong Arena (пинг-понг)
Браузерная адаптация `sketchpiponGPT.pde`: `games/pong-arena/index.html`. Два игрока: W/S и ↑/↓, 5-минутный таймер, очки, звуковые сигналы, экран победителя, перезапуск клавишей R. На сенсорном устройстве предусмотрены кнопки.

### Space Runner (космический шутер)
Браузерная адаптация исходного файла `spaceXshooter.pde`: `games/space-runner/index.html`. Движение корабля за мышью вверх-вниз (или пальцем), удержание левой кнопки мыши для автоматических выстрелов (на телефоне кнопка FIRE), метеориты, три вида космических обломков, частицы взрывов, звуки лазера/взрыва/сбора, три сердца, три жизни, счёт и R для новой игры. Звук активируется после первого действия пользователя и может зависеть от настроек браузера.


## Фильтр по устройствам (обновление)

На главной странице есть раздел **Устройства**: все / компьютеры / телефоны / планшеты.
Фильтр показывает игры, для которых в `games.js` перечислены поддерживаемые устройства.
На каждой карточке игры показываются соответствующие значки, в окне запуска — тот же перечень.

Для **новой игры** укажи поле `devices`:

```js
// Только клавиатура или мышь:
devices: ["computer"],
// Сенсорные кнопки и свайпы на мобильных устройствах:
devices: ["phone", "tablet"],
// И то и другое:
devices: ["computer", "phone", "tablet"],
```

Поле `devices` описывает **реально реализованное управление**, а не размер экрана. Все четыре нынешние игры поддерживают клавиатуру/мышь и сенсорное управление; Pong Arena использует экранные кнопки для обоих игроков. При добавлении игры без сенсорного управления не следует указывать phone/tablet, пока управление не добавлено.

### Обновление уже опубликованного GitHub Pages
Загрузи изменённые `index.html`, `app.js`, `games.js`, `styles.css` в **корень того же репозитория** (`sokol-games`), а папку `games/` сохрани со всеми её файлами. После Commit changes GitHub Pages опубликует обновление по **тому же адресу**. Для новых игр добавляй их папки и записи в `games.js`.

## 🌍 Три языка / Three languages / Tres idiomas

В верхней части сайта есть кнопки **Русский / Español / English**.
Выбранный язык сохраняется в браузере. Переведены меню, фильтры, каталог,
описания, подсказки, игровые экраны и сообщения победы/проигрыша.

Новые переводы находятся в `locale.js`, а для новых игр — ключи `subtitleKey`,
`genreKey`, `controlsKey` в `games.js`. Для самостоятельных страниц игр подключайте
`../../locale.js` и передавайте язык через `?lang=ru|es|en`.

### Обновление GitHub Pages

Загрузите **все файлы и папки** из этого архива в корень существующего репозитория
(в особенности новый файл `locale.js`), заменив предыдущие версии. Выполните
**Commit changes**. Адрес сайта не меняется. После развёртывания обновите страницу
(при необходимости Ctrl+F5). `index.html` должен быть в корне репозитория.


## Рекорды / Records / Récords

В каждой игре после окончания партии сохраняется личный максимальный результат и при новом достижении появляется окно ввода имени. Для Pong результат красного и синего игроков предлагается записать отдельно. Рейтинги каждого из четырёх игр доступны под игровым полем при прокрутке окна. Все надписи автоматически переводятся на русский, español и English.

**ВАЖНО: сейчас топ-5 локальный.** Данные записываются в localStorage браузера конкретного устройства и не синхронизируются между телефонами или посетителями. Очистка данных сайта может стереть записи. Для общего интернет-рейтинга понадобится внешний сервис хранения данных, например Supabase/Firebase, с защитой от спама и подделки результатов. GitHub Pages сам по себе не хранит присылаемые игроками очки.

Файлы обновления: index.html, styles.css, locale.js, app.js, records.js, игры в папке games/. Загрузите содержимое этой папки в корень GitHub-репозитория.
